1️⃣ Problem Statement

The problem is help people such as football clubs, coaches, scouts and sports analysts evaluate a player performance after every match and make decesions based on it so ,
The purpose of this project is to build a Machine Learning model that predicts a player's match rating using various performance statistics collected during a football match.

2️⃣ Business Question

Can we predict a football player's overall match rating using their in-game performance statistics ?

3️⃣ Target Variable: player_rating (As of Now)

4️⃣ Problem Type: Regression

5️⃣ Probable Input Features :

Age
Position
Goals
Assists
Shots
Pass Accuracy
Distance Covered
Tackles
Interceptions
Sprint Distance

The final set of input features will be determined after performing Exploratory Data Analysis (EDA), data cleaning, and feature selection.
